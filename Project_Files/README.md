This folder contains the files as they have been used in the project.

- The "Original_VOC_Dataset" folder contains the original dataset that we have been provided by the course. This dataset contains the data from the VOC trips.
- The Database folder contains the database that has been created based on the VOC-Dataset in order to provide better access to the data for analysis and visualisation
- The QGIS folder contains the QGIS project that we have created for geospatial analysis
- The "Secondary_Literature" folder contains the secondary literature that we have found combined with the notes we made on them.
