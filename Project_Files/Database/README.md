The SQL files here are to be used in PostgreSQL 4.
The schema.sql will only recreate the database-schema. The data is just the imported data from the VOC Dataset (the enriched files) and does not contain any changes, except for clarifications in terms of datatypes.

The queries_visualisation.sql file contains the queries as used for visualising the data into charts. Redash (https://redash.io/)has been used as a (Open-Source) tool to visualise the data into maps and charts. Besides this QGIS has also been used, based on this same data, in order to provide more advanced map-visualisations; more information on that can be found in the QGIS-folder.
